## Introduction

Mars3D is a 3D globe client development platform built with WebGL, enhanced from [Cesium](https://cesium.com/cesiumjs/) and designed with a B/S architecture. It is a lightweight, high-performance GIS development platform that supports multi-industry extension. It runs in browsers without installation or plugins, integrates various GIS data and 3D models, and supports 3D visualization and industry applications.

- Website: [http://mars3d.cn](http://mars3d.cn)
- Tutorials: [http://mars3d.cn/docs/](http://mars3d.cn/docs/)
- API docs: [http://mars3d.cn/api/](http://mars3d.cn/api/)
